## 3. 시장별 문법 차이

**영문권 — 원시 데이터 밀도, 해석은 사용자에게.** 산식과 티어 선언을 회피하는 대신 원시값(W-L-T, 표본수, 절대 금액)을 전부 병기하고 지표 선택권·필터를 사용자에게 넘긴다(Limitless의 랭킹 지표 5종 선택, Labs의 색상 없는 매치업 리스트). 생태계가 기능별로 분업(본체 DB / play 운영 / labs 통계 / Trainer Hill 매트릭스·도구)하며, 비용 정보가 1급 시민(덱 총액이 헤더 레벨, 어필리에이트가 수익 기둥)이다. 단 산식 자체(Points 매핑, tie=⅓승)는 미공개라는 역설이 있다 — 투명성을 "데이터 공개"로 대신하고 "정의 공개"는 생략한다.

**일본 — 편집 해설이 본체, 데이터는 근거.** 환경을 서사로 언어화하고("이번 환경의 원점은 1턴째 리리에", 환경 고찰의 【最終】박제와 누적 환경사), 티어의 산정 철학까지 본문에서 교육한다(顕在的/潜在的 구분). 고유 어휘 체계(型·平均化レシピ·採用率·立ち回り·進出率·平均CSP)와 독자 정규화 지표가 발달했고, 덱코드+공식 덱빌더+1人回し라는 실행 인프라가 레시피 노출의 기본형이다. 티어표는 영구 URL을 덮어쓰며 이미지로 SNS에 유통된다. 약점: 시티리그 단일 원천(오프시즌=휴지), 가격×메타 결합 부재, 봉입률 수치 부재(체감은 댓글로).

**한국 — op.gg 문법의 기대치 + 가격·오프라인 민감.** 자국 게이머가 학습한 표준 UX는 op.gg형(티어 뱃지+승률/픽률 동시 노출+패치 단위+티어컷 명시+"N분 전 업데이트"+표본 병기+인게임 적용 버튼)이지만, 실물 TCG에서 이를 제공하는 한국어 사이트가 없어 검색은 Pocket 콘텐츠에 점령되고 유저는 일본 티어표·CL 결과를 선행 지표로 소비한다. 고유 수요는 ① 덱 단위 가격(완덱/덱소스/저레어·고레어 소스의 이중 시장, "이 덱리면 얼마" 견적), ② 오프라인 매장·대회 위치, ③ 공식 덱코드 호환이 공유의 기본 전제, ④ 대회 후기의 정형 문법(덱리 이미지→선택 이유→"상대명(덱) OOX" 라운드 복기)이다.

## 4. 함정 목록 — 벤치마크에서 발견된 안티패턴

1. **지표 산식 미표기**: Limitless Points 매핑·Share 산식·Win%의 무승부 처리(tie=⅓승)가 전부 역산으로만 확인됨. 가장 큰 사이트조차 정의를 안 쓰니 "산식을 UI에 명시"하는 것만으로 차별점이 된다.
2. **단일 데이터 원천 의존**: 일본 전 사이트가 시티리그에 종속 → 시즌 오프=콘텐츠 전면 휴지, 갱신 중단 공지가 관행. 원천이 끊겨도 굴러갈 보조 축(자주대회·해외·온라인) 없이는 사이트가 계절상품이 된다.
3. **분석을 외부 도구에 위임**: pokekameshi의 Looker Studio 대시보드 4개 외부 링크 — 사용자를 이탈시키고 본문과 통합되지 않으며 모바일 경험이 깨진다.
4. **인프라 단일 실패점·접근성 상실**: Trainer Hill 전면 다운(커뮤니티 핵심 매트릭스가 통째로 소실), hsreplay의 Cloudflare 차단, Dash/SPA 구조로 검색 색인 불가 — SSR인 limitless·mtgtop8가 색인과 인용에서 구조적 우위.
5. **표본 없는 % / 표본 없는 티어**: 티어표 이미지가 표본·기간 없이 유통되면 신뢰가 커뮤니티 논쟁으로 전가된다("티어표에 코빼기도 안 비치는데"). JP 상위 사이트들이 표본을 헤드라인에 박는 이유.
6. **평균 레시피의 단독 노출**: 소수점 장수(4.00 Dreepy)는 실전 불가 산출물 — 표본·구간·변형 필터 명시와 실제 리스트 병행 없이는 오해 유발. "사이트가 대표 리스트 1개를 선정"하는 것도 같은 함정의 반대극.
7. **접근 장벽 높은 부가 기능**: pokekyo의 570MB Windows 전용 AI 덱 생성 앱 — 발상은 신선하나 배포 형태가 수요를 죽임. 도구는 웹 안에서 원클릭이어야 한다(1人回し·skeleton 생성기와 대비).
8. **저표본 구간의 침묵**: 신팩 직후·소수 덱 구간을 그냥 비우거나 잘라내는 것. 잘하는 곳은 규칙으로 처리한다(Other 묶음, "이번 주 14회장이라 스킵" 주석, "limited data→하위 배치" 선언).
9. **유료 벽의 불투명한 위치**: 매치업을 흔적 없이 숨기면 수요 자체가 안 보임 — untapped처럼 "Example Data"로 모양을 다 보여주고 잠그는 쪽이 전환과 신뢰 모두에서 우월.
10. **장르 불일치 지표의 직수입**: 승률이 1차가 아닌 장르가 있다(TFT=평균등수·순방률, 대회 기반 TCG=점유·컨버전). 다른 게임의 지표 세트를 그대로 가져오면 본질이 비는다.

## 5. 기회 공백 — 어느 사이트도 잘 못하는 것

1. **메타 × 가격의 통합 화면 (덱 견적)**: MTG는 가격을 붙이지만 메타 지표와 분리된 벤더 링크 수준, 일본은 가격 결합 자체가 공백(우회 어필리에이트만), 한국은 수요가 명문화돼 있으나("이 덱리면 얼마", 갤 자작 구매도움 사이트의 폭발적 조회) 공급이 없다. 특히 **레어도 옵션별 견적(플레이용 저레어 vs 과시용 고레어)**은 어디에도 없다 — Limitless의 프린트 토글(Cheapest/Max Rarity)이 유일한 맹아.
2. **무료·투명한 매치업 데이터**: 영문권은 유료 벽(untapped/hsreplay) 또는 다운된 단일 사이트(Trainer Hill), 일본은 pokekyo 1곳의 7×7 행렬뿐, 한국어는 전무. 무승부 처리·표본 컷·산식을 UI에 명시한 매치업은 전 세계에 사실상 존재하지 않는다.
3. **신팩 직후 저표본 구간의 신뢰도 설계**: D0~D+7은 수요가 최고조인데 데이터는 최소인 구간. 현존 해법은 편집 산문(JP 총평)이나 침묵뿐 — "표본 N 미만은 잠정 표기", 주차 스냅샷의 체계적 비교, 편집 평가→정량 전환의 명시적 핸드오프를 설계한 곳이 없다.
4. **오프라인 레이어(매장·대회 위치/일정)와 메타 데이터의 결합**: 한국 커뮤니티 질문의 최대 단일 유형이지만 어느 시장의 메타 사이트도 다루지 않는다(play.limitless는 온라인 대회, JP는 결과만 수집). "이번 주말 내 지역 대회 + 거기서 예상되는 메타"는 완전한 공백.
5. **운영법(回し方)의 데이터화 — 실물 TCG 버전**: hsreplay 멀리건 가이드가 디지털에서 증명한 "운영법의 통계 변환"(첫손 승률·매치업별 키핑)이 실물 TCG엔 없다. 현존은 일본식 산문 해설(고품질이나 수작업)과 자동 요약문(簡単分析)의 양극단 — 채용률 변화·사이드 구성·매치업 기록을 산문 구조(基本方針→포인트)에 자동 결합하는 중간 지대가 비어 있다.
