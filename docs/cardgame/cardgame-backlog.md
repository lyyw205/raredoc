## A. 자체 작업 (착수 가능 순서대로)

### A1. SEO 메타태그 ⭐ 추천 1순위
- **무엇**: cardgame 전 라우트에 `generateMetadata`(title/description/og 이미지) 부재 — 구글에서 "드래펄트 덱" 검색해도 덱 상세가 제대로 안 잡힘.
- **왜**: 벤치마크 핵심 발견 — **한국어 실물 TCG 메타는 검색 공백 지대**(검색이 Pocket에 점령됨). 선점은 시간 싸움.
- **작업**: 덱 상세·상성·리스트 뷰어·메타 탭부터 generateMetadata 구현. og 이미지는 아키타입 아이콘 활용.
- **규모**: S · 의존 없음

### A2. IA 정리 (sets/ 잔재 삭제)
- **무엇**: `/cardgame/sets`·`sets/[id]`가 /dex 리다이렉트만 하는 죽은 페이지로 잔존.
- **작업**: 삭제. **규모**: S(5분) · 의존 없음

### A3. 지역 비교 스트립 ⭐ 추천 2순위
- **무엇**: 덱 상세에 "🌍 글로벌 vs 🇰🇷 한국" 성적 나란히 비교 바.
- **왜**: "해외에서 뜬 덱, 한국에선 어때?"가 한국 유저 핵심 질문. 데이터(ArchetypeRegionStat)는 완비 — 화면만 달면 됨.
- **주의**: 글로벌=전 참가자 / 한국=입상자만 — **분모가 달라 usageRate 직접 비교 금지**, 동질 지표(입상률·평균등수·표본)만 나란히 (리스크 P2-5).
- **규모**: S~M · 의존 없음

### A4. 대회 메타게임 섹션
- **무엇**: 대회 상세에 "이 대회의 덱 분포" 미니 집계 (play.limitless metagame 페이지 벤치마크).
- **작업**: 해당 대회 standings의 deckKey 인라인 집계 + 점유율 바. **규모**: S · 의존 없음

### A5. 가이드 탭 개편
- **무엇**: 현재 절반이 목업 — 스타터 덱 3종 하드코딩(가격 "12,000원" 고정), FAQ 하드코딩.
- **작업**: ①스타터 덱 → 견적 엔진(budget)으로 "싸고 성적 좋은 덱 3종" 자동 선정 ②FAQ에 디시 반복 질문 3종(입문 타이밍/옛 카드 가치·레귤레이션/카운터 찾기) ③**레귤레이션 체크 위젯**("이 카드 스탠다드에서 쓸 수 있나" — 카드 검색→regMark 판정. 한국 외부 유입 1위 질문 실측).
- **규모**: M · 의존: 견적 엔진(완료)

### A6. D4 편집자산 (플레이 가이드 콘텐츠)
- **무엇**: 덱 상세 "플레이 가이드"(설명/강점/약점) — **84덱 전부 빈칸**이라 섹션 숨김 중.
- **작업**: 상위 10덱부터 작성(수동+LLM 초안, 일본식 "回し方" 해설 문법 참조). 집계가 안 건드리는 편집자산 필드라 한 번 쓰면 보존됨.
- **규모**: M(콘텐츠 작업 — 코드 아님) · 의존 없음

### A7. variant(변형) 토글
- **무엇**: "드래펄트(야느와르몽형/번치코형)" 식 빌드 분리·통합 스위치 — 같은 덱명 아래 다른 빌드가 합산돼 채용률이 뭉개지는 문제.
- **사실확인 완료**: 추가 수집 불필요 — limitless-web archetypeRaw에 변형명 보유(398행), limitless-play는 decklist 86% 보유로 **파트너 포켓몬 감지 재분류 가능**. deckIcons는 변형 구분 불가(수집기 채움차이일 뿐).
- **왜 보류**: 분류 로직이 P4 분류기와 같은 모듈 — 묶어서 만드는 게 효율적.
- **규모**: M · 의존: B2(P4 분류기)와 동근

### A8. i18n (영문판)
- **무엇**: [locale] 라우트(ko/en) 지원인데 신규 화면 전부 한국어 하드코딩.
- **정책(선언됨)**: 한국어 우선, 영문 후속 — 영문 사용자 타게팅 시점에 메시지 키 추출.
- **규모**: L · 우선순위 최하

## B. 외부 의존 (도착/완료 시 즉시 편입)

### B1. me4 (Chaos Rising) 팩 수집 → 견적 100% 마감
- **상황**: 2026-05-22 발매 신팩이 카드 DB 미수집 → 견적 미집계 7장(Meowth ex·Poké Pad 등)의 단일 원인. P1 카드 매칭률 94.8%의 잔여 원인이기도.
- **풀리면**: `npm run backfill:recipe` + `npm run deck:costs` 재실행만으로 자동 흡수(멱등).
- **주의**: 팩 수집은 **카드 파이프라인의 팩 검증 루틴(전수검증 6단계)** 대상 — 별도 캠페인으로 요청할 것.

### B2. Limitless API 키 → P4 일본 슬라이스 (잔여 최대 덩어리)
- **상황**: 키 신청 방법은 본 문서 계열 메모 참조(play 계정 → API 설정 폼, 무료·공개 프로젝트 요건). 키 = 덱 분류 규칙표(/games/PTCG/decks) + rate limit 상향.
- **풀리면**: 🇯🇵 탭 활성(시티리그 7,802건+CL 106건 공식 체인) + 메이저 무라벨 1,942명·"Hydrapple"류 미분류 일괄 해소 + A7(variant)도 같이 풀림.
- **키 없이 선작업 가능(P4의 ~70%)**: backfill-eim-jp-cardid(JP 카드ID→EIM) · collect-tournaments-jp-official(시티 3:2+CL 3:1, 휴지기=백필 적기, 덱코드 즉시 영구캐시) · enrich-cityleague-pokekameshi(키-불요 라벨 폴백).
- **착수 전 스파이크 2종**(계획 명시): 547 정답지 ≥95% + limitless-jp 라벨 보유 시티 5~10대회 덱코드 교차 ≥90%(EN↔JP 병합 공백 검출).
- 상세: `docs/cardgame/meta-pipeline-multisource.md` P4 절.

### B3. 번개장터 시세 수집기 → 견적 한국가 승격
- **상황**: PriceSource 'bunjang' 등록만(0건·비활성). 시세 파이프라인 트랙 과제(`docs/agents/price-collector-plan.md`).
- **풀리면**: 견적 기준이 "일본 매장가 환산" → **한국 실거래가 메인**으로 승격("이 덱리면 얼마"의 진짜 답). 견적 엔진의 소스 우선순위 상수만 바꾸면 됨(구조 준비됨).
