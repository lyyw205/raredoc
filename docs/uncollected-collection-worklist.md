## 공통 주의
- 그룹 2~5는 거의 다 **Limitless 경유**(WCS23와 동일 CDN 방식). TCGdex는 이 구 SWSH·SM·BW 스타터/프로모 거의 미보유.
- 스타터/프로모/트레이너박스는 **본세트 카드 재판이 다수** → 수집 시 본세트 카드와의 정체성 병합 여부(같은 일러=병합 / 프로모 별일러=고아) 점검 필요(S4a Shining Fates 케이스 참고).
- ⚠️ **MG·BGS = 2덱 구조로 통일**:
  - **BGS**(볼트로스VS토르네로스): 이미 2분리됨 — `jp-tcg-BD2`(볼트로스덱 16)·`jp-tcg-TD2`(토르네로스덱 16). 조치 없음.
  - **MG**(미츄VS게노섹트): 현재 1합본(`jp-tcg-MG` 28·`kr-mg` 34) → 번호기준 분리 가능(#001~016=게노섹트덱·#101~115=뮤츠덱). **분리 실행 대기**(구조변경, 사용자 확인 후). 뮤츠덱 #110~112 누락(수집갭).
- 세트 `code` 불일치 다수 발견(예: BKB↔BGB·BW8-Brf↔BW8S·BG 중복) → `docs/design/set-code-naming-diagnosis.md` 참조(수정 보류 중).
