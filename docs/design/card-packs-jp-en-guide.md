# 카드팩 JP↔EN 매핑 가이드

> 카드 도감 사이드바·헤더의 **단일 기준 문서**.
> JP(일본 공식) 발매를 기준으로 카테고리(시리즈)를 연대 신→구로 나열하고, 각 JP 팩에 대응하는 EN(영문/국제판) 세트를 표기한다.
>
> - **JP 측 출처**: pokemon-card.com(일본 공식) 기반 내부 감사 DB (2026-05 최신까지)
> - **EN 측 / 분기 검증**: Bulbapedia(`Browse:Trading_Card_Game` + 개별 세트 문서) 교차검증 (2026-06)
> - 코드 구현 연동: `src/lib/cards/eras.ts` (ERA_ORDER / ERA_LABEL / canonEra)

## 노출 규칙 (사이드바)

1. **카테고리 = canonical era**, `ERA_ORDER` 순서대로 노출 (신→구, 17개).
2. 카테고리 안에서는 **JP 발매 연대 내림차순**(최신 → base)으로 카드팩 나열.
3. **강화확장팩·특수상품(덱/굿즈, `*-SP`)** 은 해당 era 하단에 몰고 이름에 `()` 표기.
4. **EN 단독 발매**(JP 본탄 없음)는 별도 팩으로 빼지 않고, 팩 상세 헤더에 `EN 단독 발매` 배지.
5. **JP↔EN 1:1 / 2:1 매칭** 팩은 헤더에 `영문판: <EN 이름>` 표기.
