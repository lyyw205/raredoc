# SV 시리즈 제품 공식 분류 (나무위키 수집, 2026-06-01)

> 출처: 나무위키 — `스칼렛&바이올렛 ex 스타트 덱` 페이지의 **분류=구축덱** + **「SV 시리즈 구축덱 일람」 / 「확장팩 일람」 네비박스**, `포켓몬 카드 게임/시리즈`.
> 수집 목적: 부속상품 setGroup 분류를 나무위키 공식 체계에 맞추기 위함.

## 공식 최상위 분류

나무위키는 SV 제품을 크게 **3분류**로 나눔:

1. **확장팩 (메인 + 강화확장팩 + 하이클래스)** — 우리 본확장 setGroup들. 예: 스칼렛/바이올렛 ex, 흑염의 지배자, 레이징서프, 크림슨헤이즈, 와일드포스+사이버저지, 열풍의 아레나, 초전브레이커, 낙원드래고나, 테라스탈 페스타 ex, 배틀파트너즈, 로켓단의 영광 등.
2. **구축덱 (構築デッキ)** — 스타터 세트 / ex 스타트 덱 / 스페셜 덱 세트 / 배틀 마스터 덱 / 배틀 아카데미 / 테라스탈타입:스텔라. **(분류=구축덱 확인됨)**
3. **기타 강화상품** — 배틀 강화 BOX / ex 스페셜 세트 / 프리미엄 트레이너 박스. (구축덱 일람에 없음 → 별도)

## 현재 우리 그룹 vs 공식 분류 — 차이

- 내가 임시로 만든 4분류(starter-decks/battle-decks/battle-boxes/special-sets) 중 **`sv-special-sets`에 넣은 svg(스페셜 덱 세트)는 공식적으로 구축덱**. → 구축덱으로 이동 필요.
- `sv-battle-decks`(배틀 마스터 덱)도 공식적으로 구축덱 하위. → 구축덱으로 통합 가능.
- 즉 공식 체계를 따르면 **구축덱 1그룹 + 기타강화상품 1그룹** 의 2분류가 자연스러움.

## 추가 발견(데이터 갭)

1. **미수집 제품**: SVAM(나오하&루카리오), SVAL(뜨아거&전룡), SVI(배틀 아카데미) — DB에 없음.
2. **era 오분류**: og-svln·og-svls(테라스탈타입:스텔라)는 SV 구축덱인데 `og-` 그룹에 있음 → ✅ SV로 이동 완료.
3. **코드 불일치**: kr-sva = 꾸왁스&따라큐(공식 SVAW). setId 재검토.

### 휴리스틱 분류라 namu 재검증 대상(엣지)
- `kr-smn`(파워업덱 BOX): 덱+BOX → 현재 구축덱. namu상 기타 가능성.
- `kr-sml_`(패밀리 라이츄 GX 덱): SM 편입(패밀리 제품).
- `kr-svm`(스칼렛&바이올렛 랜덤 스타트 덱 Generations): 이름기준 SV.
- 각 부속상품 **실제 카드목록·이름은 여전히 placeholder** → 제품별 재수집은 별도(SV와 동일 과제).
