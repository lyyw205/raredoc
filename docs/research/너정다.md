# 너정다(ICU.GG) 분석 리포트

> 조사일: 2026-05-13  
> URL: https://icu.gg  
> 운영 형태: 개인 운영, 베타 서비스 중  
> 특징: 국내 유일 포켓몬 TCG 특화 카드 DB + C2C 거래 + 시세 통합 플랫폼

---

## 1. 사이트 개요

- 2022년 10월 비공개 테스트 시작, 2023년 1월부터 베타 운영
- 한글/영어/일어 3개국 카드 정보 통합 DB 보유
  - 한글 12,976개 / 영어 18,272개 / 일어 9,698개 (2024.03 기준, 총 40,946개)
- 포켓몬 외 유희왕·원피스 등 타 TCG도 일부 포함 (혼재)
- 모바일 최적화 미흡, 기능 일부 여전히 준비 중
- 카드몬스터 서비스 종료 이후 국내 TCG DB 사이트 중 사실상 유일하게 운영 중

## 2. 메뉴 구조 및 페이지별 상세

### 2-1. 카드검색 (`/card/list`)

**검색 기능**
- 카드명 한/영/일 어느 언어로 입력해도 3개국 결과 동시 조회
- 카드종류 필터 (포켓몬 / 트레이너 / 에너지)
- 확장팩 필터 (시리즈 선택 → 세트 선택)
- 정렬: 발매 최신순 / 이름순 / 번호순 등

**카드 상세 페이지 (`/card/view/{set_code}-{number}`)**

| 항목 | 상세 내용 |
|---|---|
| 카드 이미지 | 한글 / 영어 / 일어 버전 탭 전환 |
| 기본 정보 | 카드명, 확장팩명, 번호, 레어리티, 슈퍼타입, 서브타입, HP, 타입 |
| 스킬/특성 | 기술명, 에너지 비용, 데미지, 효과 텍스트 |
| 약점/저항/후퇴 | 배틀 관련 수치 |
| 일러스트레이터 | 아티스트 이름 |
| 카드 시세 | 거래 등록가 기반 **날짜별 가격 그래프 + 평균가** (시세 데이터는 너정다 거래 내역에서만 집계) |
| 카드 평점 | **성능 평점** (덱 활용도) + **수집 난이도 평점** (구하기 어려운 정도), 각 5점 만점 |
| 댓글 | 유저 코멘트 |
| 관련 카드 | 동명 카드(버전 다름), 진화 전/후 카드 링크 |

**한계**
- 시세 데이터가 너정다 자체 거래량에만 의존 → 거래가 적으면 그래프 비어있음
- 봉탕 시세(미개봉 팩 가격), 박스 시세는 제공 안 함
- 배출 확률(풀링률) 정보 없음

### 2-2. 카드거래 (`/trade/post/list`)

**구조**
- 싱글 카드 C2C 거래 전용
- 판매자가 카드 DB에서 카드를 선택 후 가격 입력 → 등록
- 구매자가 원하는 카드 선택 → 거래 신청 → 판매자와 직접 연락(채팅)
- 거래글에서 해당 카드의 시세 그래프 + 평균가 자동 표시

**거래 단위**: 카드 1장 단위 (팩·박스 거래 기능 없음)

**로그인 필요**: 거래 목록 조회조차 비로그인 불가 (접근 차단)

**한계**
- 거래량 자체가 적어 번개장터·중고나라 대비 유동성 낮음
- 팩/박스 단위 거래 미지원
- 결제 시스템 미내장 (외부 연락 방식)

---

### 2-3. 콜렉션북 (`/collection/dashboard`)

**기능**
- 보유 카드 등록 → 수집 현황 집계 (몇 % 수집했는지)
- **콜렉션 총 가치 자동 계산** (등록된 시세 기반)
- 카드별 메모 기능
- 재고 관리 용도로도 활용 가능 (판매용 재고 파악)

**로그인 필요**: 완전 차단

---

### 2-4. 덱 레시피 (`/deck/list`)

**기능**
- 덱 60장 구성 등록 및 공유
- 보기 모드: 기본 / 이미지 펼치기 / 이미지 중복 / 표 형식
- **덱 테스트 기능** (시뮬레이터, 초기 핸드 확인 등)
- 덱 공략 게시판과 연계

## 4. raredoc과의 차별화 포인트

너정다가 **카드 단위** 에 집중하는 반면, raredoc이 채울 수 있는 공백:

| 공백 영역 | 구체적 기능 |
|---|---|
| **팩 단위 시세** | 미개봉 팩 현재 봉탕가, 박스 시세 추적 |
| **팩 EV(기댓값)** | 배출 확률 × 카드 시세 = 팩 당 기댓값 계산 |
| **배출 확률 DB** | 확장팩별 레어리티 배출 비율 정리 |
| **팩 투자 지표** | 정가 대비 봉탕 프리미엄 비율, 시세 상승률 |
| **발매 예정 정보** | 신팩 발매일, 수록 카드 사전 공개 내용 |
| **한국 시세 특화** | 번개장터 실거래가 기반 원화 시세 (ICU는 자체 거래가만 반영) |
| **모바일 최적화** | 반응형 UI |

## 6. 참고 — 포켓몬코리아 공식 발매 연혁

| 연도 | 주요 이슈 |
|---|---|
| 1999 | 한국 첫 발매 (기본편/정글편) |
| 2003~2010 | 단종 기간 (공식 한글판 없음) |
| 2010 | 한글판 재출시 (하트골드소울실버부터) |
| 2020~ | 소드&실드부터 일본 발매 후 2~6개월 내 한글 동시 추격 발매 |
| 2023~ | 스칼렛&바이올렛, 일부 세트는 글로벌 동시 발매 |

> **2003~2010 단종 기간 주의**: 이 시기 카드(EX 시리즈, DP 일부)는 공식 한글판 없음 → 수집 희소성 매우 높음
