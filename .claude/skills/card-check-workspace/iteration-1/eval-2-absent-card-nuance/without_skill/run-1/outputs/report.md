# 어비스아이에 메가리자몽ex 들어있어?

**아니요, 없습니다.** 아비스아이(mega-abyss-eye)에는 메가리자몽ex가 수록되어 있지 않고, 리자몽 계열 카드 자체가 한 장도 없습니다.

## 확인 내용

- **DB 확인**: `mega-abyss-eye` setGroup의 로지컬카드 118장 / 카드로케일 118건(JP 단독 수록) 전체를 대상으로 리자몽(リザードン/리자몽/Charizard) 검색 → **0건**
- **그룹 데이터 확인**: `src/data/group-mega-abyss-eye.json` (앵커 118장, tail 0장) → 동일하게 0건

## 아비스아이의 메가진화 ex 라인업 (참고)

아비스아이의 간판 메가 ex는 다음 4종입니다 (각각 DR/SR + 일부 SAR/MUR 프린트):

- 메가제라오라ex (メガゼラオラex)
- 메가샹델라ex (メガシャンデラex)
- 메가다크라이ex (メガダークライex) — #118 Mega Ultra Rare 포함
- 메가몰드류ex (メガドリュウズex)
