# 닌자스피너 뿔충이 카드 확인 결과

## 결론: 있습니다. 한국판도 정식 발매됐습니다.

닌자스피너(JP: ニンジャスピナー, M4)의 1번 카드가 바로 뿔충이이고, DB에 일·영·한 3개 언어판이 모두 수록되어 있습니다.

| 언어판 | 카드 ID | 세트 | 번호 | 이름 | 레어도 |
|---|---|---|---|---|---|
| 일본판 | `jp-mega-ninja-spinner-1` | ニンジャスピナー (M4) | 1/120 | ビードル | コモン |
| 한국판 | `kr-m4-001` | MEGA 확장팩 「닌자스피너」 (M4) | 001/083 | 뿔충이 | 커먼 (C) |
| 영문판 | `en-tcg-me4-1` | Chaos Rising (ME4) | 1 | Weedle | Common |

- 도감번호: #13 (뿔충이) / 일러스트레이터: sowsow
- 한국판은 포켓몬코리아 공식 데이터로 확인됨 (`data/kr-official/kr-official-m4.json`, detailId `BS2026003001`, 공식 이미지 `M4_001.png` 보유)
- 닌자스피너 그룹(`src/data/group-mega-ninja-spinner.json`) 내 뿔충이 계열은 이 1장뿐 — 시크릿/얼터너티브 판본 없음

## 참고

같은 뿔충이 카드(동일 LogicalCard)가 한국판 **「MEGA 스페셜 카드 세트 메가엘레이드 ex」**(kr-m-p, #1)에도 재수록 형태로 연결되어 있습니다. 즉 한국에서는 닌자스피너 부스터 외에 스페셜 세트로도 입수 가능한 것으로 DB에 기록돼 있습니다. (단, kr-m-p 팩은 MEGA 점검 당시 보류 목록에 있던 팩이라 이 연결은 참고용입니다.)
